# CaveHD2D 基础地形 V3

打开 `Assets/Scenes/CaveHD2D.unity`，点击 Play，使用原有输入移动。本步先确认基础地形：范围、相对位置、台地轮廓和通路。建筑及道具草稿分组保持隐藏，等地形反馈后继续调整。原 `Cave` 场景保留。

## 地形与路线

地面范围保持约 126 × 100 个世界单位，Grid 每格为 2 个世界单位；角色维持已经确认的两倍显示尺寸。本版按三级台地草图重排空间关系，先验收地形。

| 区域 | 高度 Y | 布局作用 |
| --- | --- | --- |
| 左岸低地与右桥头 | -4 | 西岸保留大片连续种植、工坊用地；河道向东靠住主层崖脚，东岸低地集中在桥头 |
| 中央生活主层 | 0 | 西北约 26 × 20 的厨房与宴会空间隔开河道和大厅；中央留公共生活区，东南留仓库与训练 |
| 右侧居住中层 | +2.4、+4.8 | 约 28 × 36 的前低后高居住带，侧边坡道连接两级错台，住屋落脚面保持平坦 |
| 后方首领高台 | +10.4 | 约 40 × 24 的台地后退至中央偏右，前沿在厨房后方 |
| 右后方长老台地 | +10.4 | 约 18 × 16 的独立台地，以岩体凹口与大厅分开，4 单位宽短路连接 |

木桥在水平面上斜跨约 30°，由左后向右前接入右岸约 12 × 10 的低桥头，再经长约 12、宽 8 的坡道登上生活主层。路线为「左岸 → 斜桥 → 低桥头 → 上坡 → 生活主层」。桥面、桥头及坡道分别保存，桥面碰撞与河道通行标记同步。

登高路线为「主层 → 住区前台 → 住区后台 → 右侧弯坡与转接平台 → 长老台地 → 大厅短路」。两段住区连接坡位于西侧，后续上坡从住区后台进入，不再直接从主层绕过住区。主要路线不要求跳跃或爬梯。

岩体沿可走区域围合，后方围岩随附近高台抬高，近侧岩壁降低显示高度。可见轮廓有凹凸变化，碰撞边界守在正式格子范围内。主层贴河时，立面下沿依据相邻河格高度延伸到河床，避免悬空缺口。河床在低地以下再下沉 0.84，水面下沉 0.20；河道通过桥通行。

## 编辑与保存

- `CaveMap/LayoutGrid` 的 Floor/River Tilemaps 保存平面布局，`CaveElevation` 保存各格四角的世界高度、地面材质分区与桥面通行标记。XZ 是水平面，Y 是高度。
- `CaveMap/Geometry` 是按 16 格区块保存的地面、岩体、台地立面、水面和碰撞；`Landform` 保存岩体轮廓与基础桥梁。
- `CaveMap/Architecture` 和 `LevelRoot/PlacedProps` 保存已放置的建筑、道具草稿，当前 inactive，连同其 Collider 一起暂停。地形验收阶段保持隐藏。

普通 `Untitled → Cave → Build HD2D Scene` 和保存场景时的同步只刷新派生地形，保留正式布局、高度和手工摆放。Runtime 读取保存结果。

`Untitled → Cave → Replace With Terraced Settlement Layout` 会明确替换为本版初始地形，并隐藏已有建筑和道具，保留当前游戏镜头与场景光照。已有手工地形修改时不要使用它。`Apply HD2D Scene Lighting` 会重设光照，手工调光后无需重复执行。

此版依据 [HD-2D 场景开发经验](hd2d-scene-development.md) 中的尺度、固定镜头构图、可见地形与通行布局分离、后墙与近侧墙层次处理。镜头保持固定方向，俯角 35°、距离 28、FOV 40°；地形检查阶段关闭全局雾，便于判断轮廓。

## 验证与人工检查

检查范围为 Unity 编译、保存重载、分区高度与长老凹口，以及 Play Mode 中实际 CharacterController 的斜桥、桥头登坡、两级住区连接坡、后方上坡和大厅连接短路往返通行。边界检查覆盖低地外围、贴河主层崖岸和高台前沿。未执行完整构建。

人工检查先看总览里的宽左岸、厨房缓冲区、居住带与独立长老台地；再走一次桥头登坡和住区登高路线，确认实际游戏镜头中的层次。先确定地形，再继续建筑和生活细节。
