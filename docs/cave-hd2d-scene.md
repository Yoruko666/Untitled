# CaveHD2D 扩建地形 V2

打开 `Assets/Scenes/CaveHD2D.unity`，点击 Play，使用原有输入移动。本步先确认基础地形：范围、相对位置、台地轮廓和通路。建筑及道具草稿分组保持隐藏，等地形反馈后继续调整。原 `Cave` 场景保留。

## 地形与路线

地面范围约 126 × 100 个世界单位。Grid 每格从 1 增至 2 个世界单位，地面面积约为上一版的 3.4 倍；角色维持已经确认的两倍显示尺寸。

| 区域 | 高度 Y | 布局作用 |
| --- | --- | --- |
| 左侧河岸低地 | -4 | 弯折地下河，两岸保留种植、取水和工坊的空间 |
| 中央生活主层 | 0 | 入口朝向公共火塘，西北留厨房与宴会，西侧留酒馆，东南留仓库与训练 |
| 右侧住区台地 | +2.4、+4.8 | 两层居住平台，分别通过宽坡连接 |
| 后方首领高台 | +10.4 | 首领大厅在后方中央，长老住处在右后方，沿右侧岩壁折返上坡 |

相比最初的 -1.2 / 0 / +2.4 方案，扩建同步加大了垂直落差，并加入住区的中间层。右侧两段弯坡之间有转弯平台，上段接回高台；左侧两条下降路线和木桥形成河岸回路。主要路线不要求跳跃或爬梯。

岩体沿可走区域围合，轮廓不再是整块矩形底盘。后方岩壁较高，近侧岩壁降低显示高度。可见轮廓有凹凸变化，碰撞边界仍守在正式格子范围内；岩壁底部随最低地面下移，避免加深河谷后留下缺口。河床在低地以下再下沉 0.84，水面下沉 0.20；河道通过桥通行。

## 编辑与保存

- `CaveMap/LayoutGrid` 的 Floor/River Tilemaps 保存平面布局，`CaveElevation` 保存各格四角的世界高度、地面材质分区与桥面通行标记。XZ 是水平面，Y 是高度。
- `CaveMap/Geometry` 是按 16 格区块保存的地面、岩体、台地立面、水面和碰撞；`Landform` 保存岩体轮廓与基础桥梁。
- `CaveMap/Architecture` 和 `LevelRoot/PlacedProps` 保存已放置的建筑、道具草稿，当前 inactive，连同其 Collider 一起暂停。地形验收阶段保持隐藏。

普通 `Untitled → Cave → Build HD2D Scene` 和保存场景时的同步只刷新派生地形，保留正式布局、高度和手工摆放。Runtime 读取保存结果。

`Untitled → Cave → Replace With Terraced Settlement Layout` 会明确替换为本版初始地形，并隐藏已有建筑和道具。已有手工地形修改时不要使用它。`Apply HD2D Scene Lighting` 会重设光照，手工调光后无需重复执行。

此版依据 [HD-2D 场景开发经验](hd2d-scene-development.md) 中的尺度、固定镜头构图、可见地形与通行布局分离、后墙与近侧墙层次处理。镜头保持固定方向，俯角 35°、距离 28、FOV 40°；地形检查阶段关闭全局雾，便于判断轮廓。

## 验证与人工检查

检查范围为 Unity 编译、保存重载、代表性地面与坡道碰撞，以及 Play Mode 中的河岸坡、木桥、两层住区连接坡和折返上坡往返通行。边界检查覆盖低地外围、河岸和高台前沿。未执行完整构建。

人工检查关注地图大小、从入口看各区的相对位置、走到河岸及高台时的高度变化。先确定地形，再继续建筑和生活细节。
