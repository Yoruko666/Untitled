# CaveHD2DLocal 潜行地形 V6

打开 `Assets/Scenes/CaveHD2DLocal.unity`，点击 Play，使用原有输入移动。本版围绕观察、绕行、掩护与撤退调整地形、镜头和必要掩体占位。原建筑与道具草稿保持隐藏，新增 `StealthBlockout` 独立显示。当前没有守卫巡逻、发现判定或声音诱导，掩体与多路线为后续潜行玩法提供空间。原 `Cave` 场景保留。

## 两份场景的用途

本次 merge 将两侧的场景分别保存，不把它们的布局、对象摆放或光照混合成一份。

| 场景 | 保留内容 | 后续使用 |
| --- | --- | --- |
| `Assets/Scenes/CaveHD2DLocal.unity` | 本地潜行地形 V6：两条大厅路线、住区前后巷、实体掩体与更高俯角镜头 | 继续本地地形编辑与路线验收；下文描述此场景 |
| `Assets/Scenes/CaveHD2D.unity` | 远端版本的布局与最新道具摆放 | 查看和继续远端场景编辑 |

本地场景改名时保留原 `.meta` GUID；远端场景使用独立的新 GUID。两份场景仍共享项目中的脚本、Prefab、材质及部分网格资源，修改共享资源可能同时影响两份场景。道具行为采用合并后的 `HybridProp` 实现。

`Build HD2D Scene` 固定打开远端版 `CaveHD2D.unity`，`Apply HD2D Scene Lighting` 也仅接受该场景。`Replace With Terraced Settlement Layout` 现在明确打开本地版 `CaveHD2DLocal.unity`，用于替换本轮基础地形；已有手工地形修改时不要使用。`Rebuild Scene Geometry` 作用于当前打开场景。保存时的地形同步仍按当前场景执行；两份场景按各自 GUID 保存派生地形。

此前 merge 检查了两份场景与各自输入版本的内容一致性、独立 GUID 和冲突清除。本轮仅更新本地版地形，下文的验证记录属于 V6；远端版未进行新的玩法验证。

## 地形与路线

聚落主体保持原有尺度；右后方因长老台地右移和弯曲支路局部扩展约 10 个世界单位，河道向前后延长后的 Floor 范围约 136 × 124。Grid 每格为 2 个世界单位；角色维持已经确认的两倍显示尺寸。本版继续按三级台地草图调整基础地形。

| 区域 | 高度 Y | 布局作用 |
| --- | --- | --- |
| 左岸低地与右桥头 | -4 | 西岸保留大片连续种植、工坊用地；河道向东靠住主层崖脚，东岸低地集中在桥头 |
| 中央生活主层 | 0 | 西北约 26 × 20 的厨房与宴会空间隔开河道和大厅；中央留公共生活区，东南留仓库与训练 |
| 右侧居住中层 | +2.4、+4.8 | 前后两组住区之间有共同道路；前组向右下延伸，后组位于折返上坡内侧，外围主层空地收紧 |
| 后方首领高台 | +7.2 | 保留后方中央偏右的位置，前沿拆为 +2.4／+4.8 两段短退台，厨房仍位于河与大厅之间 |
| 右后方长老台地 | +7.2 | 保留向右移动约 8 个世界单位的独立轮廓，从上坡弯道分出支路，台上有观察掩体 |

木桥在水平面上斜跨约 30°，由左后向右前接入右岸约 12 × 10 的低桥头，再经长约 12、宽 8 的坡道登上生活主层。路线为「左岸 → 斜桥 → 低桥头 → 上坡 → 生活主层」。桥面、桥头及坡道分别保存，桥面碰撞与河道通行标记同步。

登高主路为「主层 → 弯曲入口坡 → 两组住区之间的道路 → 环抱后组住区的东侧弯道 → 向左上坡 → 大厅前沿入口」。以平滑中心线取代长直坡和直角转弯，再将四角高度保存到原有格子；主路宽约 6.4 个世界单位。转弯处分出宽约 4.4 的曲折支路，向右后方登上长老台地。主路直接接大厅，不经过长老台地。前后两组住区各有入口，后组的东侧、北侧被上坡道路环抱。主要路线不要求跳跃或爬梯。

西侧供给路线为「右桥头 → 原斜桥 → 左岸工坊 → 上游窄供给桥 → 厨房后侧 → 西侧曲折登坡 → 大厅侧边」。供给桥长约 14、宽 3 个世界单位，连接 -4 的两岸，东侧短坡进入 0 的厨房。大厅侧坡宽约 4.8，从厨房独立上行至 +7.2，与东侧主路分开进入大厅，不合并为唯一窄口。

前组住区新增第二处街道连接坡，棚屋占位之间留前街、两侧小巷和后巷；后组住区以一条 +4.8 的曲折后巷绕过两处棚屋并接回街道。两组各自形成可双向绕行的小环路，全部依靠地面与坡道连通。

河道后端延长至亮洞口，保存岩框、洞外亮面与照入河谷的局部光源；前端经过斜桥后分成两支，延伸到前方岩壁外。河道接触地图边缘时，派生围岩留出流水开口。洞口表现为基础地形与光照，尚不包含场景切换。

低岸与桥面基准为 -4，水面为 -6.2，河床为 -7.4。`CaveElevation.RiverSurfaceDrop` / `RiverBedDrop` 分别保存世界单位下沉量 2.2 / 3.4。桥面约比水面高 2.28，桥墩伸到河床；河格不再提供看不见的岸高碰撞地板，桥面和护栏保存独立 Collider。

岩体沿可走区域围合，后方围岩随附近高台抬高，近侧岩壁降低显示高度。可见轮廓有凹凸变化，碰撞边界守在正式格子范围内。岸边立面伸至实际河床，围岩底部也随加深后的河床下移。

沿两岸、河湾和分叉的陆地边缘生成独立 `RiverAirWalls` MeshCollider，高于岸面至少 3 个世界单位，没有 Renderer。空气墙与可见低矮岸沿分开；边缘厚度覆盖轮廓偏移并封住格角。两座桥各按实际 `BridgeDeck` Collider 的水平投影裁出缺口，避免较宽的 Bridge 格子标记留下漏口。两座桥侧均有无 Renderer 的 `BridgeAirWall` BoxCollider，保持桥头往返通行。后续感知实现应排除这两类移动边界，由可见地形和掩体负责视线遮挡。

## 掩体与可见性

`Landform/StealthBlockout` 中有 23 处实体掩体：两侧桥头观察位置、工坊墙与货垛、厨房炉体与后侧货垛、公共区外围岩体、仓库外围货垛、五处住区棚屋、大厅入口和长老观察位置。桥面与公共区中央保持开阔，绕行路线经过分散的掩体；必要的通行间隙保留。

占位掩体高约 2.6–3.4，均保存 BoxCollider，可阻挡移动和实际视线射线。棚屋是实心占位体，当前不提供室内空间。视觉材质沿用项目地形 shader，前景遮挡严重时由已有 `CaveWallReveal` 在角色附近局部显露；Collider 始终保留。低矮装饰和明暗不默认代表隐蔽状态，高台也不默认安全。

## 编辑与保存

- `CaveMap/LayoutGrid` 的 Floor/River Tilemaps 保存平面布局，`CaveElevation` 保存各格四角的世界高度、地面材质分区与桥面通行标记。XZ 是水平面，Y 是高度。
- `CaveMap/Geometry` 是按 16 格区块保存的地面、岩体、台地立面、水面和碰撞；`Landform` 保存岩体轮廓、基础桥梁和亮洞口。
- `CaveMap/Architecture` 和 `LevelRoot/PlacedProps` 保存已放置的建筑、道具草稿，当前 inactive，连同其 Collider 一起暂停；必要掩体保存于 active 的 `Landform/StealthBlockout`。

保存场景时的同步只刷新当前场景的派生地形，保留正式布局、高度和手工摆放。Runtime 读取保存结果。`Untitled → Cave → Build HD2D Scene` 固定作用于远端版 `CaveHD2D.unity`。

`Untitled → Cave → Replace With Terraced Settlement Layout` 会明确替换本地版场景为本版初始地形，重建 Landform 和掩体，并隐藏旧建筑和道具。此明确替换操作也应用本版镜头与本地后处理参数；普通保存与几何重建保留手工摆放。已有手工地形修改时不要使用替换菜单。`Apply HD2D Scene Lighting` 会重设远端版场景的光照，手工调光后无需重复执行。

此版依据 [HD-2D 场景开发经验](hd2d-scene-development.md) 中的尺度、固定镜头构图、可见地形与通行布局分离、后墙与近侧墙层次处理。镜头保持固定方向与透视投影，俯角 42°、yaw 0°、距离 32、FOV 34°、Focus Offset `(0, 1.6, 2)`。镜头同时展示角色、当前穿越区域和后续落脚面，角色 Visual 仍保持两倍显示尺寸与 upright Billboard。

本地 Volume 使用独立的 `Assets/Settings/CaveHD2DLocalPresentation.asset`，Gaussian DOF 从相机深度 45 到 70 逐渐作用，最大半径 0.5；活动区域清晰，原远端后处理资产保留。全局雾继续关闭，未重新调整场景灯光。

## 验证与人工检查

Unity 编译与保存重载通过，保存 2866 个地形格。Play Mode 中使用实际 CharacterController 检查两条大厅路线、前后台地小环路、长老支路和桥头登坡的双向通行；沿河检查 198 处岸边阻挡，角色未进入河格或跌落。23 处掩体均阻挡实际物理射线。总览及桥头、生活区、上坡、大厅四处实际游戏镜头已保存。未执行完整构建；巡逻、发现与声音诱导效果待感知系统接入后验证。

人工检查：从桥头和生活区观察后续掩体与落脚点；分别走东侧主路与西侧供给路到大厅并绕行住区；沿河岸与两座桥侧移动确认防跌落。先确认地形、掩体与镜头，再接入巡逻和感知。
