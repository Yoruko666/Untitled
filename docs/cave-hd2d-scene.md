# CaveHD2D 基础地形 V4

打开 `Assets/Scenes/CaveHD2D.unity`，点击 Play，使用原有输入移动。本步先确认基础地形：范围、相对位置、台地轮廓和通路。建筑及道具草稿分组保持隐藏，等地形反馈后继续调整。原 `Cave` 场景保留。

## 地形与路线

聚落核心保持原有约 126 × 100 个世界单位的尺度，河道向前后延长后整体范围约 126 × 124。Grid 每格为 2 个世界单位；角色维持已经确认的两倍显示尺寸。本版继续按三级台地草图调整基础地形。

| 区域 | 高度 Y | 布局作用 |
| --- | --- | --- |
| 左岸低地与右桥头 | -4 | 西岸保留大片连续种植、工坊用地；河道向东靠住主层崖脚，东岸低地集中在桥头 |
| 中央生活主层 | 0 | 西北约 26 × 20 的厨房与宴会空间隔开河道和大厅；中央留公共生活区，东南留仓库与训练 |
| 右侧居住中层 | +2.4、+4.8 | 前后两组住区之间有共同道路；前组向右下延伸，后组位于折返上坡内侧，外围主层空地收紧 |
| 后方首领高台 | +10.4 | 约 40 × 24 的台地后退至中央偏右，前沿在厨房后方 |
| 右后方长老台地 | +10.4 | 独立台地保留，以岩体凹口与大厅分开，由上坡转弯处的支路进入 |

木桥在水平面上斜跨约 30°，由左后向右前接入右岸约 12 × 10 的低桥头，再经长约 12、宽 8 的坡道登上生活主层。路线为「左岸 → 斜桥 → 低桥头 → 上坡 → 生活主层」。桥面、桥头及坡道分别保存，桥面碰撞与河道通行标记同步。

登高主路为「主层 → 两组住区之间的道路 → 后组住区东侧上坡 → 转弯平台 → 向西上坡 → 大厅前沿入口」。不经过长老台地。长老支路从转弯平台向北上坡，旧的大厅与长老之间的必经短路已移除。前后两组住区各有入口，后组的东侧、北侧被上坡道路环抱。主要路线不要求跳跃或爬梯。

河道后端延长至亮洞口，保存岩框、洞外亮面与照入河谷的局部光源；前端经过斜桥后分成两支，延伸到前方岩壁外。河道接触地图边缘时，派生围岩留出流水开口。洞口表现为基础地形与光照，尚不包含场景切换。

低岸与桥面基准为 -4，水面为 -6.2，河床为 -7.4。`CaveElevation.RiverSurfaceDrop` / `RiverBedDrop` 分别保存世界单位下沉量 2.2 / 3.4。桥面约比水面高 2.28，桥墩伸到河床；河格不再提供看不见的岸高碰撞地板，桥面和护栏保存独立 Collider。

岩体沿可走区域围合，后方围岩随附近高台抬高，近侧岩壁降低显示高度。可见轮廓有凹凸变化，碰撞边界守在正式格子范围内。岸边立面伸至实际河床，围岩底部也随加深后的河床下移。

## 编辑与保存

- `CaveMap/LayoutGrid` 的 Floor/River Tilemaps 保存平面布局，`CaveElevation` 保存各格四角的世界高度、地面材质分区与桥面通行标记。XZ 是水平面，Y 是高度。
- `CaveMap/Geometry` 是按 16 格区块保存的地面、岩体、台地立面、水面和碰撞；`Landform` 保存岩体轮廓、基础桥梁和亮洞口。
- `CaveMap/Architecture` 和 `LevelRoot/PlacedProps` 保存已放置的建筑、道具草稿，当前 inactive，连同其 Collider 一起暂停。地形验收阶段保持隐藏。

普通 `Untitled → Cave → Build HD2D Scene` 和保存场景时的同步只刷新派生地形，保留正式布局、高度和手工摆放。Runtime 读取保存结果。

`Untitled → Cave → Replace With Terraced Settlement Layout` 会明确替换为本版初始地形，并隐藏已有建筑和道具，保留当前游戏镜头与场景光照。已有手工地形修改时不要使用它。`Apply HD2D Scene Lighting` 会重设光照，手工调光后无需重复执行。

此版依据 [HD-2D 场景开发经验](hd2d-scene-development.md) 中的尺度、固定镜头构图、可见地形与通行布局分离、后墙与近侧墙层次处理。镜头保持固定方向，俯角 35°、距离 28、FOV 40°；地形检查阶段关闭全局雾，便于判断轮廓。

## 验证与人工检查

检查范围为 Unity 编译、保存重载、分区与河水高度，以及 Play Mode 中实际 CharacterController 的斜桥与桥头登坡、直达大厅的主路、长老支路及住区入口往返通行。边界检查覆盖贴河主层崖岸、高台前沿和桥梁护栏。未执行完整构建。

人工检查先看两组住区与上坡的关系、右下空地及河道两端；再走一次大厅主路和长老支路；最后到桥边确认水面落差与亮洞口。先确定地形，再继续建筑和生活细节。
