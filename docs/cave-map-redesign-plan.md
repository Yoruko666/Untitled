# 哥布林洞穴整图改造：多路线潜入与固定镜头探索

日期：2026-10-12。版本：V6。阶段：低俯角下的三段地图修订。

实施场景为 `Assets/Scenes/CaveHD2DLocal.unity`。本轮沿用最新约 `12.09°` 的固定方向镜头，修改入口到火塘、供给桥到厨房、住区上坡到大厅三个区域的手工对象，继续使用建筑占位。

**本轮修改已写入场景文件；未重新打开 Unity 场景、输出新截图或进行试玩、通行、感知与性能验证。** 文末图片属于上一轮 `30°` 镜头，不能作为本轮结果。

## 1. 设计依据与保留项

体验目标为「看到方向线索 → 观察与选路 → 穿越暴露段 → 到达遮挡 → 继续探索或撤退」。

《合金装备》的公开手册说明，被发现后可以逃跑或躲藏，失去玩家视线后会搜索失去目标附近。本项目据此预留转角、分散遮挡与返回环路，没有接入这些敌人行为。[官方潜行手册](https://www.konami.com/mg/mgs5/gz/webmanual/xb1/ja/p0060.html)

《八方旅人 II》开发者说明，探索使用固定镜头，并尽量让玩家想去的地点出现在同一画面内。本项目采用分段显露目标与接近路线的方式，不要求入口与真实大厅同屏。[开发者访谈](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style?lang=en-US)

路线、间距和具体摆放是本项目的设计推导，不是两部作品的原始关卡参数。原 [2D 功能图](images/cave_functional_plan_reference.png) 保留功能种类，[三级台地图](images/cave_settlement_reference.png) 提供区域关系，均不作为精确施工尺寸。

保留河谷、三级台地、角色根节点 `0.9` 缩放、五处住宿棚屋、四块种植床和两座桥。每格为 2 世界单位，低岸 `-4`、主层 `0`、住区 `2.4 / 4.8`、大厅与长老台地 `7.2`；水面、河床、灯光与后处理设置沿用原配置。本轮未改 Floor/River Tilemaps、`CaveElevation` 或派生地形网格。

普通建筑的入口柱框移到门洞外侧，保留 `2.4` 世界单位的净开口，大厅净开口为 `3.2`。这些是保存的几何尺寸，尚未做角色通行测试。

## 3. 路线与空间职责

- **东侧主路：**入口 → 火塘东侧 → 住区前街 → 上坡连接 → 折返坡 → 大厅正面。公共区与前场较开阔，棚屋转角提供局部遮挡。
- **西侧供给路：**入口附近桥头 → 左岸工坊 → 供给桥 → 厨房后侧 → 西侧供给坡 → 大厅侧面。转角较多，两座桥保持开放穿越段。
- **换路与撤退：**火塘—厨房、火塘—住区坡口、仓库—入口，以及住区前后巷环路。返回入口不必经过大厅目标区域。

正式地面材质重新描出这些连接，物件与建筑缺口表达边界；观察标记只负责定位设计位置。主坡约 `6.4`、供给坡约 `4.8` 世界单位宽度沿用原基线，住区通巷以至少 `2.4` 的净宽为摆放约束。

桥头、坡口和转角以至少约 `3×4` 世界单位的落脚空间为制作目标，掩体放在侧边。分散掩体之间以约 `6–10` 世界单位的开放段为摆放起点，不沿整条路线铺连续遮挡墙。这些设计间距没有通过动态通行或感知验收。

本轮构图意图为：入口以火塘暖色占位作为下一处目标，供给桥通过横向接近与烟囱轮廓指向厨房，上坡通过大厅宽前场、浅色旗架与私库青色小屋区分两处目标。是否在最新机位下连续显露，尚未检查。

供给桥的新增货垛位于桥面侧边，用于形成出发前、返回后的停留与遮挡空间；大厅掩体退到前场侧后方，避免在门前堆成遮挡墙。装饰占位不带 Collider，新货垛与前场低石块带 BoxCollider；视觉辨识与物理遮挡分开处理。

不标记安全位置、发现概率、穿越时间窗口或隐蔽系数；没有守卫、巡逻、感知、导航、任务、战斗或其他新增 runtime API。

## 4. 相机与保存

Cinemachine `2.10.7` 沿用任务开始时的最新配置：Perspective、Pitch 约 `12.09°`、Yaw/Roll `0°`、FOV `34°`、Camera Distance `24.6`、Tracked Object Offset `(0,1.6,0)`、Screen X/Y `0.5/0.6`。三轴 Damping `0.25`；Dead Zone Width/Height `0.05`、Depth `0`；Soft Zone Width/Height `0.8`、Bias `0`。这些是本项目参数，不是《八方旅人》公开的标准角度。

Body 为 Framing Transposer，Aim 为 Do Nothing，Follow 玩家根节点，Look At 留空；Brain 两项更新方式均为 Late Update。旧 `CameraController` 保持禁用并保留目标引用，其 `30° / 32` 字段不是当前镜头参数。URP、Volume 与 `CaveWallReveal` 引用保留。

Floor/River Tilemaps 与 `CaveElevation` 是正式布局及高度来源。本轮未改这些数据，派生网格保持原保存结果，不需要为新增占位重新生成地形。

手工建筑与地标保存在 `Landform/MapProduction`，五处棚屋及新桥头货垛在 `StealthBlockout`。岩肩、短围栏与方向标识位于 `15_SpatialConnections`。三个本地占位材质为 `map_landmark_bone`、`map_landmark_ember` 和 `map_landmark_teal`；旧 `Architecture` 与 `PlacedProps` 保持隐藏。

普通保存与当前场景的 `Rebuild Scene Geometry` 保留手工编辑；不要使用 `Replace With Terraced Settlement Layout` 刷新，它会替换正式布局。本轮没有新增通用 Editor 框架。
