## 潜行空间

中央、供应及外围三条接近路线均保留；建筑正门、服务门、后室和暗道接入它们。食堂—火塘等换路连接保持可走。货堆、实墙、岩体提供碰撞和绕行空间；观察、警戒及私库目标位置保存为空定位点。

长老暗道已移除 Demo 末端封墙，书柜保持移开状态；出口接实际地形回程坡道。未添加动画、钥匙、锁门或任务条件。Demo 静态角色不是具备巡逻和感知的守卫。

## 美术与资源

地图用组合 Prefab 位于 `Assets/Prefabs/Levels/CaveSettlement/`。结构实体表面统一到 64px、Point 和 16 px/m；像素图集、透明裁切与方向帧按原资源合同保留。材料在地图专用目录共享，不覆盖 Demo 材质。

近侧墙采用剖面，墙体碰撞仍为完整边界；后侧窄顶棚保留轮廓。展示相机与全局补光没有随 Demo 导入，地图继续使用保存的 18.10° 默认跟随相机和原画面配置。

`SettlementBuildings` 与 `SettlementGameplay` 独立于地形根节点。首次组装读取布局 JSON 的分区定位，保存后由 Scene 与 Prefab 实例承载可编辑摆放。地形重导入保留建筑，重复整合会明确拒绝覆盖。

## 已做检查与剩余范围

Unity 编译及 Shader 检查通过；15 处区域和 910 个地形路线高度采样通过。保存玩家的 CharacterController 双向验证通过 26 段地形路线及 8 组室内连接，并验证三处南侧边界阻挡。

仍需按实际输入试玩判断构图、材质观感和遮挡。当前没有新增守卫 AI、警报、蹲伏、声音、任务结算或经营系统；空间预留不能作为这些玩法已经实现的证据。
