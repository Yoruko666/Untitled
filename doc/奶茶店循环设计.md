# 奶茶店循环设计

> 文档用途：独立说明“制作饮品—经营获利—升级准备—异世界采集—带回新原料”的核心循环。
> 规则状态：已确认内容直接作为当前设计；待试玩参数和待决事项单独标注，不视为已定案。
> 本次修订：完全单机运行，饮品由本地预设配方、固定文案模板和预制图片构成，不接入运行时图文或生图模型。品质与售价公式保持不变。完整的 180 款配方见 [奶茶店预设配方目录](奶茶店预设配方目录.md)。

## 1. 循环概览

```text
获得现实与异世界原料
→ 选择预设配方，或选择原料及用量进行自选调配
→ 系统计算品质分布，匹配本地配方并读取名称、描述和图片
→ 玩家确认并保存配方
→ 开店前确定菜单、摆放当日原料
→ 顾客到店或外卖订单进入队列
→ 点击订单饮品，系统自动制作；玩家手动交付
→ 获得金币并扣除原料成本
→ 解锁现实原料、购买道具、提升食材品质或升级店铺
→ 带上合适道具进入异世界采集原料
→ 成功带回原料，解锁图鉴并扩充配方选择
→ 回到经营与探索循环
```

经营的主要作用是产出金币、使用已收集原料并提供购买与升级入口；异世界探索则带回新原料，扩充可制作的饮品和菜单。首版不设置必须达成的经营指标。

## 2. 原料来源与加工

奶茶配方可使用两类原料：

| 原料类型 | 获取方式 | 制作时的处理 |
|---|---|---|
| 现实食材 | 通过经营系统解锁；解锁后持续供应，不因库存耗尽而断供 | 每杯按低价单位成本扣费 |
| 异世界食材 | 玩家进入异世界采集并带回 | 制作时消耗已带回的库存 |

现实食材的“持续供应”不代表免费：解锁后可持续用于制作，但每杯仍产生低价原料成本。异世界食材的售价溢价不是采购成本；其成本计价方式尚待确定，带回库存仍会实际消耗。

每种原料在配方中可以选择一种加工方式：

- 切丁：读取小颗粒配料图层，以及预先编写的颗粒口感文案。
- 切块：读取块状配料图层，以及预先编写的块状口感文案。
- 榨汁：读取液体色彩配置，以及预先编写的融合风味文案。

加工方式只影响本地文案、配料形态和外观，不改变原料品质分数，也不参与品质概率计算。茶液、鲜奶、糖浆等本来就是液体的原料直接使用，不要求再次榨汁；其他原料可选的加工方式由原料表明确配置。不能对茶液等液体选择切块，也不把未配置的加工方式自动替换为其他方式。

## 3. 配方品质

### 品质档位

原料和成品使用五档品质：普通、优秀、稀有、史诗、传奇，对应分数 `1` 至 `5`。

每份原料用量换算成统一的配方贡献点，再按贡献点计算原料占比 `w_i`，所有占比之和为 `1`。配方品质中心和品质差异为：

```text
平均品质 μ = Σ(w_i × 原料品质分数_i)
品质差异 V = Σ[w_i × (原料品质分数_i - μ)^2]
```

当配方原料全部为同一品质时，成品固定为该品质。混合品质时，以 `μ` 为中心，根据离散正态权重计算五档概率：

```text
σ = 0.4 × √V
a_k = exp(-(k - μ)^2 / (2σ^2))
P(k) = a_k / Σa_k       k ∈ {1, 2, 3, 4, 5}
```

若 `V=0`，使用前述同品质规则，避免 `σ=0` 时计算无定义。混合配方可能产出中间品质；例如 60% 普通和 40% 传奇的配方，平均品质为 `2.6`，概率主要集中在优秀与稀有，同时保留其他档位的可能性。

创建配方时按概率抽取一次成品品质，并随配方保存；重复制作沿用该结果。品质分布公式中的 `0.4` 是建议初始值，最终公式与参数需试玩确认。预设配方、名称、描述与图片不得改写游戏计算出的品质、售价或原料清单。

## 4. 本地预设配方与保存

### 4.1 单机创建流程

```text
选择一款已满足原料解锁条件的预设配方，或自行选择原料及用量
→ 确认每种原料支持的加工方式
→ 校验原料、用量和加工配置，匹配本地配方
→ 游戏系统按第 3 节公式计算分布并抽取一次品质
→ 读取预设名称、描述和图片；自选组合使用固定的通用模板
→ 玩家确认并保存配方
```

游戏包须包含配方表、原料表现表、名称与描述模板、杯型与配料素材。设计要求：断网时创建、保存、制作和售卖饮品应正常运行，不出现下载生成图片、等待模型响应或消耗模型额度的步骤。配方目录是设计数据，经营与图片合成代码尚未在洞穴 demo 中实现。

### 4.2 预设配方的覆盖与匹配

本轮目录包含 120 款现实饮品和 60 款异世界饮品。现实饮品覆盖原叶茶、奶茶、水果茶、水果奶、奶盖、珍珠黑糖、布丁与冻、抹茶可可、谷物坚果根茎、咖啡、清爽饮品和多料甜品；异世界饮品覆盖当前实际存在的荧光菇、红浆果、洞穴根茎的三种单料、三种双料及三料组合。

目录配比使用统一贡献点，单杯合计 100 点；它们是首轮设计配比，不是克数、毫升数、原料品质或强制固定售价。单种原料实际消耗量按该原料的“单位用量对应贡献点”换算，品质与溢价计算继续使用 `w_i = 该原料贡献点 / 总贡献点`。贡献点与实际库存单位的换算参数须在经营实现前配置并测试，不能将一件洞穴食材直接当成一整杯或一份茶液。

匹配与确认遵循以下顺序：

1. 原料必须已解锁，用量为正，加工方式受该原料支持。零用量原料从组合中移除；负用量、空配方或未知原料不能确认。不因原料品质低而禁止组合。
2. 使用原料 ID、加工方式及规范化贡献占比匹配目录，输入顺序不影响匹配；原料品质不参与配方外观的匹配。只有原料集合、加工方式和占比均一致时，使用该预设的正式名称及展示配置。占比以整数贡献点约分后比较，避免浮点误差。
3. 玩家调整配比、增减原料或改变加工方式后，不偷偷恢复默认配方，也不删除不匹配的材料。未精确命中的合法组合进入第 4.3 节的本地自选模板；品质、库存消耗和售价仍依据实际输入。
4. 预设配方只提供默认配比和展示内容，不固定成品品质。名称含“传奇”等品质词的展示标签必须在抽取后根据实际结果添加，目录本身不设置品质保底或额外加成。

### 4.3 未命中预设时的离线自选模板

允许玩家继续自由调配，避免有限目录阻断探索带回的食材。自选模板也是事先定义的数据与规则，不能临时调用模型创造新配方。

| 实际原料条件（按从上到下的优先级） | 固定模板名称 | 本地杯身表现 |
|---|---|---|
| 有咖啡液 | 自选咖啡饮 | 咖啡底色，加实际存在的奶、果汁及固体图层 |
| 无咖啡液，有茶液或抹茶液且含奶基底 | 自选奶茶 | 茶奶底色，加实际配料 |
| 无咖啡液，有茶液或抹茶液且不含奶基底 | 自选茶饮 | 茶底色，加实际果汁及配料 |
| 无以上基底，含鲜奶、椰奶或其他奶基底 | 自选奶饮 | 奶底色，加实际果汁及配料 |
| 无以上基底，含榨汁原料、预制液体或气泡水 | 自选调和饮 | 对应液体底色，加实际配料 |
| 无液体，全部为可食用固体或现成配料 | 自选配料杯 | 中性杯型，只显示实际固体；不能画出未加入的奶或茶 |

文案采用固定结构：“以〔实际基底〕为底，搭配〔其他实际原料清单〕；〔对应加工口感短句〕。成品品质：〔实际品质〕。”没有基底时用“由〔实际原料清单〕调配”。各个占位内容均来自本地原料表，原料清单完整显示，不使用未实际加入的风味名称。仅改变输入顺序不能改变名称、外观或品质结果；同贡献量按原料 ID 排序。

加工短句固定为“液体融合”“小颗粒口感”“块状配料”，可按原料配置专用短句。玩家可以为保存的饮品手动起名；自定义名称只改变展示，不改变原料或计算结果。

### 4.4 预制图片与本地组合

预设饮品优先读取随游戏打包的专用图片；尚未配置专用图或属于自选组合时，按本地表现表组合已有 2D 素材：杯体、基底色、果汁色、切丁或切块配料、确实加入的奶盖，以及品质边框。素材制作可由开发阶段完成，游戏运行期间只读取资源或进行本地图层组合。

- 每种支持使用的原料必须配置液体色或固体图层及默认处理方式。图层不能添加配方里没有的水果、珍珠、奶盖或其他配料。
- 液体颜色按实际液体贡献占比混合，固体按切丁／切块选择素材；荧光菇是否使用微弱发光表现由其本地素材决定，不赋予饮品新的数值效果。
- 品质以五档边框与文字显示，杯内原料表现由配方决定。高品质不会凭空增加金箔或改变原料组成。
- 所有存在的固体种类均在配料列表显示。杯图可按贡献量优先画有限图层，并明确它是示意图；不能因此少扣原料或隐去配方明细。
- 图片资源缺失时使用包内的中性杯体及原料文字列表，品质计算、保存和售卖仍可完成。素材完整性由打包检查单独验证。

### 4.5 配方保存与重复制作

| 数据对象 | 保存内容 | 归属 |
|---|---|---|
| 预设配方 | 配方 ID、名称、分类、原料与默认贡献点、加工方式、固定描述、图片／表现配置 ID | 随游戏打包，只读数据 |
| 原料配置 | 原料 ID、来源、解锁条件、支持加工、贡献点换算、固液分类、奶／茶等基底标签、表现配置 | 随游戏打包，只读数据 |
| 玩家配方 | 匹配的预设 ID 或自选模板 ID、实际原料与用量、加工方式、创建时原料品质快照、品质分布及抽取结果、最终名称／描述、图片引用或组合参数 | 本机存档 |

配方第一次有效创建时抽取一次品质，同一组合再次打开、取消预览后重开、确认保存或重复制作都沿用该次结果。组合身份由实际原料 ID、加工方式、规范化用量和创建时原料品质快照确定；不能通过更名、调整输入顺序或重复套用同一个预设来重抽。该规则落实原有“一次抽取并保存”要求，不增加品质公式。

确认保存不消耗异世界库存；制作每杯时才扣对应库存和原料成本。配方可在带回食材后解锁，即使后来库存耗尽也保留图鉴和配方；缺货期间不能制作，但可继续查看。原料品质升级后已保存配方是否重算，继续保留第 7 节的待定状态，本次不擅自决定。

本机存档保存素材引用或本地组合参数即可，不需要联网获取图片。名称、描述、图片表现与抽取品质随保存结果固定；修改原料或用量时按新组合处理，不能只换显示数据而沿用旧配方的消耗清单。

## 5. 售价、成本与金币

### 售价

异世界原料的 `5–10` 倍是**成品售价溢价**，不是采购成本溢价。每种异世界原料配置一个溢价系数 `m_i`，范围为 `5` 至 `10`。配方中异世界原料占比越高，售价溢价贡献越大：

```text
异世界溢价因子 W = 1 + Σ[w_i × (m_i - 1)]  （仅对异世界原料求和）
成品售价 = round(常规基础售价 × 品质售价系数 × W)
```

配方完全不含异世界原料时 `W=1`；完全由溢价系数为 `5` 或 `10` 的异世界原料构成时，`W` 分别为 `5` 或 `10`。现实与异世界原料混合时按原料占比加权。

品质售价系数的建议试玩起始值：

| 成品品质 | 建议售价系数 |
|---|---:|
| 普通 | 1.0 |
| 优秀 | 1.25 |
| 稀有 | 1.6 |
| 史诗 | 2.0 |
| 传奇 | 2.5 |

这些品质售价系数是待试玩调整的初始参数，由游戏配置决定，不由名称、图片或配方类别决定。

### 成本与净收入

```text
单杯原料费 = Σ(本杯用量 × 对应原料单位成本)
单杯净收入 = 成品售价 - 单杯原料费 - 单杯运营成本
```

已确认：解锁的现实食材持续供应，但每杯收取低价成本。待定：具体单位成本、单杯运营成本，以及异世界食材是否计入现金成本。无论现金成本如何设定，异世界食材都从玩家带回的库存中扣除。

## 6. 菜单、备料与售卖

| 阶段 | 规则 |
|---|---|
| 确定菜单 | 开业前从已保存配方中选择当日菜单 |
| 摆放食材 | 最多摆放 12 种固体配料和 5 种液体原料 |
| 接收订单 | 柜台顾客和外卖订单进入同一订单队列 |
| 制作饮品 | 玩家点击订单饮品，系统按保存配方自动制作并扣除原料与成本 |
| 交付订单 | 玩家手动交付，完成售卖结算并获得金币 |

12 种固体配料和 5 种液体原料是经营时的摆料种类上限，不是配方原料用量上限。订单所需原料未摆放或库存不足时，不能自动制作。首版不设计外卖配送路线和配送计时。

## 7. 金币用途：解锁、购买与升级

金币用于解锁现实食材、购买现实道具和升级店铺。现实道具应遵守现实物品原则，并且不替代伙伴的特殊能力：

| 项目 | 设计效果 | 状态 |
|---|---|---|
| 足力健老人鞋 | 提高玩家移动速度 | 效果幅度与价格待定 |
| 强光手电筒 | 照到目标眼睛时造成短暂失明 | 持续时间、使用限制与价格待定 |
| 金币巧克力 | 外观模仿金币，但不能用于贿赂 | 价格与使用方式待定 |
| 超级登山包 | 增加背包空间 | 容量与价格待定 |
| 超级外骨骼 | 提高可承受负重 | 增幅与价格待定 |

现实食材可逐步解锁；解锁后持续供应，每杯制作仍扣低价原料费。现实食材品质升级会改变其原料品质分数，后续配方按新分数重新计算。已保存配方是否随品质升级重新计算成品品质，尚待确定。

店铺升级优先提供新菜单位、提高订单队列容量或扩充展示内容，不直接倍增金币收入。各升级的具体价格、层级和数值待后续设计。

## 8. 进入异世界与循环回流

玩家以经营获得的金币和已购买的道具进入异世界，采集异世界原料并尝试带回。带回成功后：

- 异世界原料进入可用库存，可用于创建或制作配方。
- 首次成功带回的原料解锁对应图鉴。
- 新原料解锁对应的本地预设配方，并支持离线自选组合；成品售价继续按实际配方占比计算。
- 经营制作实际消耗已带回的异世界食材；库存可通过后续探索补充，探索中已经消耗的食材不能再次入库或用于制作。

因此，经营为探索提供金币和装备准备，探索为经营提供新原料和高售价饮品的可能性；玩家可在两部分之间反复切换。

## 9. 待定参数清单

以下内容目前没有最终数值或规则，不应作为已经确认的开发常量：

- 混合原料品质分布公式是否采用离散正态方案，以及 `σ` 公式中的 `0.4` 参数。
- 各品质的最终售价系数、常规基础售价和每种异世界原料的溢价系数。
- 现实食材单位成本、异世界食材现金成本及其他单杯运营成本。
- 现实道具的价格、效果数值、持久性和使用限制。
- 现实食材品质升级的价格，以及已保存配方是否随升级重算品质。
- 店铺升级的价格、层级、菜单位和订单队列容量。
- 目录中新增现实原料的解锁顺序、贡献点与实际消耗单位的换算，以及每款默认配比的口味与收益平衡。
- 预制杯图、配料图层及原料表现的最终美术资源；本轮交付配方与展示规则设计，不代表 180 款专用图片已制作。
